# Security Audit & Compliance

## Project Overview

This project focuses on conducting a security controls assessment and identifying gaps in an organization's security posture.

The assessment included reviewing existing security controls and identifying areas that required improvement to better protect sensitive information.

## Objectives

The main objectives of this project were to:

- Assess existing security controls
- Identify security weaknesses and gaps
- Review access control practices
- Evaluate password policies
- Assess encryption practices
- Identify areas requiring additional security controls
- Provide recommendations to improve the organization's security posture

## Security Controls Reviewed

The assessment included the following security controls:

- Least Privilege
- Disaster Recovery Plans
- Password Policies
- Separation of Duties
- Firewall
- Intrusion Detection System (IDS)
- Backups
- Antivirus Software
- Legacy System Maintenance
- Encryption
- Password Management System

## Compliance Frameworks

The project also included a review of security practices in relation to:

- PCI DSS
- GDPR
- SOC

## Key Findings

Several security gaps were identified during the assessment, including:

- Lack of Least Privilege controls
- Weak password policies
- Lack of encryption for sensitive information
- Missing disaster recovery plans
- Lack of an IDS
- No password management system
- Insufficient asset classification

## Recommendations

The following improvements were recommended:

- Implement the Principle of Least Privilege
- Strengthen password policies
- Implement encryption for sensitive data
- Deploy an Intrusion Detection System (IDS)
- Develop disaster recovery plans
- Implement a password management system
- Improve asset classification processes
