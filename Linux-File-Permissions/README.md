# Linux File Permissions

## Project Overview

This project demonstrates practical Linux skills related to managing and auditing file and directory permissions.

## Objective

The objective of this project was to analyze existing file permissions and modify them according to security requirements and the principle of least privilege.

## Tasks Performed

- Inspected file and directory permissions using `ls -la`
- Analyzed permission strings
- Modified file permissions using `chmod`
- Updated permissions for hidden files
- Modified directory permissions
- Verified changes after applying security controls

## Tools and Technologies

- Linux
- Bash / Linux CLI
- `chmod`
- `ls -la`

## Skills Demonstrated

- Linux administration
- Access control
- File permissions management
- Principle of Least Privilege
- Security configuration

## Key Takeaway

This project demonstrates how Linux file and directory permissions can be reviewed and modified to reduce the risk of unauthorized access.
