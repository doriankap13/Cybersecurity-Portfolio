# DDoS Incident Analysis

## Project Overview

This project focuses on analyzing a Distributed Denial of Service (DDoS) incident involving an ICMP flood attack.

The analysis documents the impact of the incident and outlines security measures used to protect network services and support recovery.

## Incident Summary

The organization experienced a security incident involving a large volume of incoming ICMP packets. The attack affected internal network resources and required the cybersecurity team to protect and restore critical network services.

## NIST Cybersecurity Framework

The incident was analyzed using the following functions of the NIST Cybersecurity Framework:

### Identify

- Identified the security incident and its impact on internal network resources.
- Identified critical network services requiring protection and recovery.

### Protect

- Implemented firewall rules to limit incoming ICMP traffic.
- Used IDS/IPS controls to filter suspicious ICMP traffic.

### Detect

- Configured source IP verification to identify potentially spoofed IP addresses.
- Implemented network monitoring to detect abnormal traffic patterns.

### Respond

- Isolated affected systems to prevent further disruption.
- Worked to restore critical systems and services.
- Reviewed network logs for suspicious and unusual activity.
- Reported security incidents to appropriate management and authorities when applicable.

### Recover

- Restored critical network services.
- Planned the controlled restoration of non-critical services after the attack.
- Implemented measures to reduce the impact of future ICMP flood attacks.
